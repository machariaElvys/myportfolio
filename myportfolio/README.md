# Macharia — Portfolio

A responsive React and Vite portfolio. Project details live in `src/data/projects.js`; update the project links and descriptions there as work is completed.

The site includes responsive navigation, project case studies, and a light/dark theme toggle that remembers your choice.

## Run it from the terminal

1. Extract the ZIP file.
2. Open a terminal in the extracted `macharia-portfolio` folder.
3. Run:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. You’ll need Node.js installed. The project uses CSS-built previews and does not need separate image assets.
